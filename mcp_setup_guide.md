# 🚀 Power Apps MCP Server — Setup Guide

## What Is This?

A **Model Context Protocol (MCP) Server** that lets **Antigravity (AI)** directly manage your Microsoft Power Platform — create SharePoint lists, Dataverse tables, Power Automate flows, and Canvas Apps through natural language.

## Step 1: Register Azure AD App

1. Go to **https://portal.azure.com**
2. Search **"App registrations"** → Click **"+ New registration"**
3. Fill in:

| Field | Value |
|-------|-------|
| Name | `PowerApps MCP Server` |
| Account types | `Single tenant` |
| Redirect URI | Leave blank |

4. Click **Register**

### Copy These 3 Values:

| Value | Where | Example |
|-------|-------|---------|
| **Client ID** | Overview page | `8850a951-7703-464b-...` |
| **Tenant ID** | Overview page | `3bc4f820-9e33-4a47-...` |
| **Client Secret** | Certificates & secrets → + New | `abc123~DEFghi...` |

> [!CAUTION]
> Client Secret shows **ONLY ONCE**. Copy it immediately!

---

## Step 2: Add API Permissions

Go to **API permissions** → **+ Add a permission**:

### Microsoft Graph (Application)
| Permission | Purpose |
|-----------|---------|
| `Sites.ReadWrite.All` | Read/write SharePoint |
| `Sites.FullControl.All` | Create/delete SharePoint lists |

### Dynamics CRM (Application)
| Permission | Purpose |
|-----------|---------|
| `user_impersonation` | Access Dataverse (tables, flows, apps) |

### Then Click: **✅ Grant admin consent**

> [!IMPORTANT]
> Without "Grant admin consent", you'll get 403 Forbidden errors!

### Verify — Should Look Like:
| API | Permission | Status |
|-----|-----------|--------|
| Microsoft Graph | Sites.ReadWrite.All | ✅ Granted |
| Microsoft Graph | Sites.FullControl.All | ✅ Granted |
| Dynamics CRM | user_impersonation | ✅ Granted |

---

## Step 3: Get Dataverse URL

1. Go to **https://make.powerapps.com**
2. Click **⚙️ gear** (top right) → **Session details**
3. Copy **"Instance url"**:
   ```
   https://org1234abc.crm.dynamics.com
   ```

> [!TIP]
> India region: `crm8.dynamics.com` | Europe: `crm4.dynamics.com` | US: `crm.dynamics.com`

## Step 4: Clone & Install

```bash
git clone https://github.com/Lokesh121100/Power-Automate_MCP.git
cd Power-Automate_MCP
npm install
```

---

## Step 5: Configure Credentials

### Option A: Create `.env` file
```env
AZURE_TENANT_ID=your-tenant-id
AZURE_CLIENT_ID=your-client-id
AZURE_CLIENT_SECRET=your-client-secret
DATAVERSE_URL=https://your-org.crm.dynamics.com
```

### Option B: Update `mcp-config.json`
```json
{
  "mcpServers": {
    "powerapps": {
      "command": "node",
      "args": ["dist/index.js"],
      "cwd": "C:/full/path/to/Power-Automate_MCP",
      "env": {
        "AZURE_TENANT_ID": "your-tenant-id",
        "AZURE_CLIENT_ID": "your-client-id",
        "AZURE_CLIENT_SECRET": "your-client-secret",
        "DATAVERSE_URL": "https://your-org.crm.dynamics.com"
      }
    }
  }
}
```

## Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `401 Unauthorized` | Wrong Client ID/Secret | Re-check Azure AD |
| `403 Forbidden` | Missing permissions | Grant admin consent |
| `404 Not Found` | Wrong Dataverse URL | Check Instance URL |
| `AADSTS700016` | Wrong Tenant ID | Verify in Azure Portal |
| `AADSTS7000215` | Expired secret | Create new secret |
| `Permission not working` | Propagation delay | Wait 5-15 min |
